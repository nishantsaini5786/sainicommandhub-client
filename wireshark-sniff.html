What is Wireshark Sniffing?

Wireshark can capture and dissect network packets so you can inspect protocols, endpoints, conversations and application metadata. Capture filters reduce what is collected before capture; display filters control what is shown after packets are captured. For encrypted traffic such as HTTPS/TLS, packet capture normally exposes connection metadata rather than plaintext application content unless you have an appropriate authorized decryption setup.

Core Sniffing Workflow

1. Select the correct interface → 2. Start a controlled capture → 3. Apply a capture/display filter → 4. Inspect protocols, endpoints and conversations → 5. Follow streams where appropriate → 6. Save the PCAP/PCAPNG → 7. Document findings.

Wireshark / TShark Command Reference

Authorized Use

Only capture traffic on networks, devices and systems where you have permission. Packet captures can contain sensitive information, including internal addresses, cookies, application data and authentication material. Store PCAP files securely and avoid collecting traffic that you do not need for the investigation.
