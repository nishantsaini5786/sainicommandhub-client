Nmap (Network Mapper) is the industry-standard open-source tool for network discovery and security auditing. It uses raw IP packets to determine hosts, services, operating systems, packet filters, and hundreds of other characteristics. Used by network admins, pentesters, and ethical hackers worldwide.

What is Nmap?

Nmap is a free, open-source utility for network discovery and security auditing. Originally released in 1997 by Gordon Lyon (Fyodor), it has become the de-facto standard for network reconnaissance.

Nmap is not just a port scanner. It can:

  • Discover live hosts on a network (host discovery)
  • Enumerate open ports and identify services (port scanning)
  • Detect service versions (banner grabbing + fingerprinting)
  • Identify operating systems via TCP/IP stack fingerprinting
  • Run vulnerability scripts via the Nmap Scripting Engine (NSE)
  • Bypass firewalls and IDS/IPS using advanced evasion techniques
  • Map entire networks with topology and traceroute data
💡
Why it matters: Before exploiting anything, you must know what's there. Nmap is the first tool in every penetration tester's arsenal.

Basic Syntax
nmap [Scan Type] [Options] {target specification}
  • Target — IP address, hostname, CIDR range, or file with targets
  • Options — flags like -sV, -O, -p, -A etc.
Basic Commands
1. Single Host Scan
Scans the top 1000 TCP ports on a single target — most commonly used first command.
nmap 192.168.1.1
Starting Nmap 7.94 ( https://nmap.org ) Nmap scan report for 192.168.1.1 Host is up (0.0021s latency). Not shown: 997 closed tcp ports (reset) PORT STATE SERVICE 22/tcp open ssh 80/tcp open http 443/tcp open https
2. Multiple Hosts
Scan multiple IP addresses at once.
nmap 192.168.1.1 192.168.1.5 192.168.1.10
3. Scan a Subnet (CIDR)
Scan entire /24 network — 254 hosts.
nmap 192.168.1.0/24
4. Scan From File
Read targets from a text file (one per line).
nmap -iL targets.txt
5. Scan a Range
Scan IP range using dash syntax.
nmap 192.168.1.1-50
Host Discovery (Ping Scans)
6. Ping Sweep (-sn)
Find live hosts without scanning ports. Fastest way to map a network.
nmap -sn 192.168.1.0/24
Nmap scan report for 192.168.1.1 Host is up (0.002s latency). Nmap scan report for 192.168.1.10 Host is up (0.005s latency).
7. Skip Host Discovery (-Pn)
Treat all hosts as online — skip ping. Useful when ICMP is blocked by firewall.
nmap -Pn 192.168.1.1
8. TCP SYN Ping (-PS)
Use TCP SYN packets for host discovery (bypasses ICMP filtering).
nmap -PS22,80,443 192.168.1.1
9. ARP Ping (-PR)
For local networks — faster than ICMP. Works even if ICMP is blocked.
nmap -PR 192.168.1.0/24
10. Disable DNS Resolution (-n)
Speed up scans by skipping reverse DNS lookups.
nmap -n 192.168.1.0/24
Port Scanning Techniques
11. TCP SYN Scan (-sS) — Stealth
The default and most popular scan. Fast, stealthy, never completes TCP handshake. Requires root.
sudo nmap -sS 192.168.1.1
12. TCP Connect Scan (-sT)
Full TCP handshake scan. Works without root but slower and noisier than SYN.
nmap -sT 192.168.1.1
13. UDP Scan (-sU)
Scan UDP ports. Slower than TCP but discovers DNS, SNMP, DHCP services.
sudo nmap -sU 192.168.1.1
PORT STATE SERVICE 53/udp open domain 67/udp open|filtered dhcps 161/udp open snmp
14. Combined TCP + UDP
Scan both TCP and UDP in one command.
sudo nmap -sS -sU 192.168.1.1
15. ACK Scan (-sA)
Maps firewall rules. Distinguishes filtered vs unfiltered ports.
sudo nmap -sA 192.168.1.1
16. FIN Scan (-sF)
Stealthy scan — sends FIN packets. Bypasses some firewalls.
sudo nmap -sF 192.168.1.1
17. XMAS Scan (-sX)
Sends packets with FIN+PSH+URG flags — reveals open ports on some systems.
sudo nmap -sX 192.168.1.1
18. NULL Scan (-sN)
Sends packets with no flags set.
sudo nmap -sN 192.168.1.1
Port Selection
19. Scan Specific Ports (-p)
nmap -p 22,80,443 192.168.1.1
20. Scan Port Range
nmap -p 1-1000 192.168.1.1
21. Scan ALL 65535 Ports
Full port scan — slow but thorough.
nmap -p- 192.168.1.1
22. Fast Scan — Top 100 Ports
Scan only the top 100 most common ports.
nmap -F 192.168.1.1
23. Top N Ports
Scan top 500 most common ports.
nmap --top-ports 500 192.168.1.1
24. Scan All TCP Ports
nmap -p T:1-65535 192.168.1.1
Service & Version Detection
25. Service Version Detection (-sV)
Detect service name and version on each open port. Critical for finding vulnerable software.
nmap -sV 192.168.1.1
PORT STATE SERVICE VERSION 22/tcp open ssh OpenSSH 8.2p1 Ubuntu 4ubuntu0.5 80/tcp open http Apache httpd 2.4.41 ((Ubuntu)) 443/tcp open ssl/https
26. Aggressive Version Detection
More probes, slower but more accurate.
nmap -sV --version-intensity 9 192.168.1.1
27. OS Detection (-O)
Identify the operating system via TCP/IP stack fingerprinting.
sudo nmap -O 192.168.1.1
Running: Linux 4.X|5.X OS CPE: cpe:/o:linux:linux_kernel:4 OS details: Linux 4.15 - 5.6
28. Aggressive Scan (-A)
All-in-one scan: OS detection + version detection + script scanning + traceroute.
sudo nmap -A 192.168.1.1
29. Aggressive with More Probes
sudo nmap -A --version-all 192.168.1.1
Nmap Scripting Engine (NSE)

NSE has 600+ scripts. Categories: default, safe, vuln, auth, brute, discovery, exploit, malware, intrusive.

30. Default Scripts (-sC)
Run default NSE scripts — safe, useful for reconnaissance.
nmap -sC 192.168.1.1
31. Vulnerability Scan
Run all vulnerability detection scripts.
sudo nmap --script vuln 192.168.1.1
32. Brute Force Login ⚠ AUTHORIZED USE ONLY
Brute-force login on supported services (SSH, FTP, etc.).
nmap --script ssh-brute -p 22 192.168.1.1
33. HTTP Enumeration
nmap --script http-enum -p 80,443 192.168.1.1
34. SMB Enumeration
Enumerate SMB shares, users, OS info — critical for Windows networks.
nmap --script smb-enum-shares,smb-enum-users -p 445 192.168.1.1
35. SMB Vulnerabilities (MS17-010)
Check if target is vulnerable to EternalBlue.
nmap --script smb-vuln-ms17-010 -p 445 192.168.1.1
36. SSL/TLS Enumeration
nmap --script ssl-enum-ciphers -p 443 192.168.1.1
37. DNS Enumeration
nmap --script dns-zone-transfer -p 53
38. MySQL Enumeration
nmap --script mysql-info,mysql-enum -p 3306 192.168.1.1
39. Show Script Help
Read documentation for any NSE script.
nmap --script-help smb-enum-shares
40. Run Category Scripts
Run all scripts in the discovery category.
nmap --script "discovery" 192.168.1.1

nmap -T5 192.168.1.0/24

Send at least 300 packets per second.
nmap --min-rate 300 192.168.1.1

nmap --max-parallelism 100 192.168.1.0/24
Firewall / IDS Evasion
45. Fragment Packets (-f)
Split packets into tiny fragments to bypass simple packet filters.
sudo nmap -f 192.168.1.1
46. Decoy Scan (-D)
Hide your IP among decoys. Target sees multiple source IPs.
sudo nmap -D RND:10 192.168.1.1
47. Spoof MAC Address
sudo nmap --spoof-mac 0 192.168.1.1
48. Custom Source Port
Use DNS source port (53) which is often allowed through firewalls.
sudo nmap --source-port 53 192.168.1.1
49. Append Random Data
sudo nmap --data-length 200 192.168.1.1
Output Formats
50. Normal Output (-oN)
nmap -oN scan.txt 192.168.1.1
51. XML Output (-oX)
Machine-readable XML — used for tooling integration.
nmap -oX scan.xml 192.168.1.1
52. Grepable Output (-oG)
Easy to grep / parse with awk / sed.
nmap -oG scan.gnmap 192.168.1.1
53. All Formats (-oA)
Saves .nmap, .xml, and .gnmap together.
nmap -oA scan 192.168.1.1
54. Verbose Output (-v)
Show progress in real-time.
nmap -v 192.168.1.1
55. Debug Mode (-d)
nmap -d 192.168.1.1
Advanced & Combined Scans
56. The Ultimate Pentest Scan
Combines aggressive scan + all ports + version + scripts + OS detection.
sudo nmap -A -p- -T4 -sC -sV 192.168.1.1
57. Fast Discovery + Detailed Scan
Step 1: fast discovery. Step 2: detailed scan of live hosts only.
nmap -sn 192.168.1.0/24 -oG - | awk '/Up$/{print $2}' > live.txt nmap -iL live.txt -sV -T4
58. Compare Two Scans
See what changed between scans — useful for monitoring.
nmap -oX scan1.xml 192.168.1.1 nmap -oX scan2.xml 192.168.1.1 ndiff scan1.xml scan2.xml
59. Zenmap (GUI)
Graphical frontend for Nmap — great for beginners.
zenmap
60. Traceroute (--traceroute)
Map the network path to target.
nmap --traceroute 192.168.1.1
Practical Workflows

Beginner Workflow — Simple Recon

Step 1: Host Discovery
Find live hosts on your local network.
nmap -sn 192.168.1.0/24
Step 2: Port Scan
Scan a live host for open ports.
nmap -F 192.168.1.5
Step 3: Service + OS Detection
Identify services and OS.
sudo nmap -sV -O 192.168.1.5
Step 4: Save Results
Export in all formats for reporting.
sudo nmap -sV -O -oA recon 192.168.1.5

Advanced Workflow — Full Pentest

Step 1: Fast Network Discovery
nmap -sn -T4 192.168.1.0/24 -oG live.txt
Step 2: Full TCP + UDP Scan
sudo nmap -sS -sU -p- -T4 --min-rate 1000 192.168.1.5
Step 3: Deep Service Analysis
sudo nmap -sV --version-all -sC -O --traceroute -p 192.168.1.5
Step 4: Vulnerability Scripts
sudo nmap --script vuln -p 192.168.1.5
Step 5: Report Generation
nmap -oA full-scan 192.168.1.5

Real-World Use Cases

1. Network Inventory

Discover all devices on a corporate network — routers, servers, printers, IoT.

nmap -sn -PR 10.0.0.0/24

2. Penetration Testing

Full port scan, service enumeration, and vulnerability detection on authorized targets.

sudo nmap -A -p- -T4 -sC -sV --script vuln <authorized-target>

3. Security Auditing

Verify firewall rules — see which ports are actually exposed.

nmap -sA -p 1-1000 <firewall-ip>

4. Compliance & Monitoring

Detect unauthorized services/apps appearing on the network.

nmap -sV -p 1-10000 10.0.0.0/24 -oA audit-$(date +%Y%m%d)

5. Bug Bounty Recon

Discover live hosts, subdomains, and exposed services for bug bounty programs.

nmap -iL subdomains.txt -sV -T4 --open -oA bounty-recon
Troubleshooting

Scan shows all ports as filtered

  • Firewall is dropping packets — try -Pn or -sA
  • Try --source-port 53 to bypass simple filters
  • Use -f for packet fragmentation

Nmap is too slow

  • Use -T4 or -T5
  • Add -n to skip DNS lookups
  • Use --min-rate 1000
  • Scan only specific ports: -p 22,80,443

Permission denied

  • SYN, UDP, OS detection require root — use sudo
  • Or use -sT (TCP connect) which doesn't need root

Missing NSE scripts

  • Update Nmap: sudo apt update && sudo apt upgrade nmap
  • Scripts located at /usr/share/nmap/scripts/
