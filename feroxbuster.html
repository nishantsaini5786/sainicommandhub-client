FEROXBUSTER

Feroxbuster is a fast, simple, recursive content discovery tool written in Rust. It brute-forces directories and files on web servers to find hidden endpoints, admin panels, backup files, and more. Feroxbuster's killer feature is automatic recursion — when it finds a directory, it automatically scans inside it without manual intervention. It's the modern replacement for Dirbuster and Gobuster.

What is Feroxbuster? (Deep Theory)

Web servers often have hidden files and directories not linked anywhere on the site:

  • /admin/ — admin panel
  • /api/v1/ — API endpoints
  • /backup.zip — site backup
  • /.env — environment variables with secrets
  • /config.php.bak — config backup
  • /.git/ — exposed source repository
  • /phpinfo.php — PHP info leak

Feroxbuster brute-forces these paths using wordlists. What makes it different from other tools:

Key Differences from Other Tools

  • Automatic Recursion — Finds /admin/, then automatically scans inside it
  • Written in Rust — Extremely fast, memory-safe
  • Smart Filtering — Auto-detects and skips wildcard responses
  • Multi-Extension — Tests multiple file extensions simultaneously
  • Parallel Scanning — Multiple concurrent requests
  • Clean Output — Color-coded, easy to read
  • Resume Support — Save state and continue later
  • Auto-Tuning — Dynamically adjusts threads based on errors

How Feroxbuster Works Internally

  1. Loads wordlist(s) and extensions
  2. Launches N concurrent requests (default 50)
  3. Analyzes response codes and content lengths
  4. Skips "wildcard" responses (custom 404s)
  5. On finding a directory (200/301/302), queues it for recursion
  6. Recursion continues up to N levels (default unlimited)
  7. Auto-tunes concurrency based on server responses
  8. Reports findings in real-time with color coding
💡
Why it's fast: Rust + async I/O + smart filtering. Feroxbuster can do 200+ requests/sec while other tools do 20-30/sec. For a 100,000-word scan, this saves hours.
Real-World Use Cases

1. Bug Bounty Recon

After finding live subdomains, Feroxbuster discovers hidden endpoints on each host. Often finds admin panels, API versions, and debug routes.

2. Penetration Testing

Discover application structure before manual testing. Map every accessible endpoint and file.

3. Finding Sensitive Files

Locate .git/, .env, backup.zip, db.sql, config.php.bak — often critical findings.

4. API Endpoint Discovery

Find undocumented API versions (/api/v1/, /api/v2/, /api/admin/).

5. CTF Challenges

Web CTFs hide flags in directories. Feroxbuster finds them via wordlist + extensions.

6. Attack Surface Mapping

Map every accessible path before automated scanning.

7. Continuous Monitoring

Run Feroxbuster periodically to detect new endpoints appearing (DevOps mistakes).

8. Fuzzing Alternative

When you need a fast brute-force but ffuf is too complex, Feroxbuster's defaults work well.

Basic Commands
1. Basic Scan
Scan a URL with default wordlist — recursion is ON by default!
feroxbuster -u http://target.com
200 GET 15l 25w 345c http://target.com/ 200 GET 10l 20w 234c http://target.com/index.html 301 GET 7l 13w 234c http://target.com/admin => http://target.com/admin/ 200 GET 5l 10w 123c http://target.com/admin/login.php 200 GET 3l 5w 89c http://target.com/api/v1/users 403 GET 10l 20w 300c http://target.com/.htaccess
2. Use Custom Wordlist
feroxbuster -u http://target.com -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt
3. Test Specific Extensions
Find files with these extensions.
feroxbuster -u http://target.com -x php,html,js,txt,bak,zip
4. Limit Recursion Depth
Only scan N levels deep.
feroxbuster -u http://target.com -d 3
5. Disable Recursion
Only scan top-level, don't recurse into found directories.
feroxbuster -u http://target.com -n
6. Increase Threads
Faster scan but more aggressive.
feroxbuster -u http://target.com -t 100
7. Scan Multiple URLs
feroxbuster -u http://target.com -u http://target2.com
8. URLs from File
feroxbuster --stdin < urls.txt
Filtering & Response Handling
9. Filter by Status Code
Hide specific status codes.
feroxbuster -u http://target.com -C 404,500
10. Status Codes to Filter (Default)
Default hides 404. Use -C to add more.
feroxbuster -u http://target.com --status-codes 200,301,302,401,403
11. Filter by Content Length
feroxbuster -u http://target.com -S 1234
12. Filter by Line Count
feroxbuster -u http://target.com -L 5
13. Filter by Word Count
feroxbuster -u http://target.com -W 10
14. Filter by Regex (URL)
feroxbuster -u http://target.com --filter-url "logout"
15. Auto-Tune Scanning
Auto-reduce threads on errors (rate limit, timeouts).
feroxbuster -u http://target.com --auto-tune
16. Auto-Tune with Interactive Controls
feroxbuster -u http://target.com --auto-tune --interactive
HTTP Configuration
17. Custom User-Agent
feroxbuster -u http://target.com -A "Mozilla/5.0 (X11; Linux x86_64)"
18. Random User-Agent
feroxbuster -u http://target.com --random-agent
19. Custom Headers
feroxbuster -u http://target.com -H "Authorization: Bearer token123" -H "X-Custom: value"
20. Cookies
feroxbuster -u http://target.com -b "session=abc123; user=admin"

24. Timeout Control
feroxbuster -u http://target.com -T 10
25. Delay Between Requests
feroxbuster -u http://target.com --rate-limit 50
Output & Reporting
26. Save Output to File

27. JSON Output
feroxbuster -u http://target.com --json -o output.json
28. Quiet Mode
Minimal output — good for piping.

Advanced Techniques
32. Multiple Wordlists
feroxbuster -u http://target.com -w list1.txt -w list2.txt -w list3.txt
33. Brute Force Extensions
Also discover extensions themselves (e.g., .php vs .php7).
feroxbuster -u http://target.com -x php,php7,php5,phtml
34. Match Specific Response
feroxbuster -u http://target.com --filter-regex "Welcome to nginx"
35. Scan with Host Header Injection
feroxbuster -u http://target.com -H "Host: internal.target.com"
36. Scan Behind Auth
Include session cookie for authenticated scan.
feroxbuster -u http://target.com -b "PHPSESSID=abc123def456"
37. Resume Previous Scan
Continue where you left off.
feroxbuster -u http://target.com --resume-from state.json
38. Save State Automatically
feroxbuster -u http://target.com --save-state state.json
39. Limit Total Requests
Stop after N requests (avoid overload).
feroxbuster -u http://target.com --limit-bars 5000
40. Ignore 403 Forbidden
Some servers return 403 for all paths — filter them.
feroxbuster -u http://target.com -C 403
Complete Workflow — Bug Bounty Recon
Step 1: Enumerate Subdomains
subfinder -d target.com -o subs.txt
Step 2: Filter Live Hosts
cat subs.txt | httpx -silent -o live.txt
Step 3: Run Feroxbuster
feroxbuster --stdin < live.txt -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,html,js,txt,bak,zip -d 4 -t 100 -o ferox-results.txt
Step 4: Filter Interesting Findings
Look for: /admin, /api, /.git, /.env, /backup, /config
Step 5: Save JSON for Tooling
feroxbuster --stdin < live.txt --json -o ferox.json
Step 6: Manual Testing
Open discovered URLs in browser/Burp. Test for IDOR, auth bypass, info leak.
Step 7: Chain with Other Tools
Feed URLs to Nuclei, XSStrike, SQLmap, or Burp Intruder.

Troubleshooting

"Too many 200 responses with same length"

  • Wildcard response — server returns 200 for any path
  • Feroxbuster auto-detects and skips by default
  • Manually filter: -S 1234 (response length)
  • Use --filter-regex "Not Found"

"Scan is very slow"

  • Increase threads: -t 200
  • Reduce extensions: -x php
  • Use smaller wordlist
  • Reduce recursion depth: -d 2
  • Disable recursion: -n

"Rate limited / 429 responses"

  • Reduce threads: -t 10
  • Add rate limit: --rate-limit 20
  • Use --auto-tune
  • Use proxy rotation

"WAF blocking requests"

  • Reduce threads: -t 5
  • Random User-Agent: --random-agent
  • Slower rate: --rate-limit 10
  • Try HTTP/1.1 explicitly

"Recursion never stops"

  • Site has infinite recursive paths — set depth: -d 3
  • Add filter for common patterns
  • Use -C 404,500 to skip dead ends

"SSL certificate errors"

  • Use -k to ignore SSL errors
  • Update system CA certificates
  • Check target's SSL config

"Command not found"

  • Install: sudo apt install feroxbuster
  • Or cargo install feroxbuster
  • Check PATH: which feroxbuster

"Memory usage is high"

  • Reduce threads
  • Use smaller wordlist
  • Limit recursion depth
  • Disable state saving: --no-state
Pro Tips
  • Chain with httpx: cat live.txt | feroxbuster --stdin -w list.txt
  • Pipe to grep: feroxbuster -q | grep -i admin
  • Extract URLs: feroxbuster --json | jq -r '.url' | sort -u
  • Auto-tune always: Add --auto-tune to every scan
  • Save state for big scans: --save-state scan.json
  • Use Burp proxy: -p http://127.0.0.1:8080 for manual analysis
  • Combine wordlists: cat list1.txt list2.txt > combined.txt
  • Add extensions based on tech: PHP app? -x php,php7,phtml,inc
