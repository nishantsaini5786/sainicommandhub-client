CYBERCHEF
Utilities · The Cyber Swiss Army Knife
Beginner 400+ Operations Encoding Crypto Forensics

CyberChef is a web-based, browser-only tool developed by GCHQ (UK's intelligence agency) that makes it easy to perform complex data manipulation without writing code. It has 400+ operations — encode, decode, encrypt, decrypt, hash, parse, extract, and analyze data. It's called the "Cyber Swiss Army Knife" because it does everything. And it works offline — no data leaves your browser.

What is CyberChef? (Deep Theory)

Imagine you have a blob of data. You need to: base64-decode it, then XOR it, then gunzip it, then extract IPs, then parse as JSON. In a terminal, this requires multiple tools and pipes. CyberChef does it all in one GUI with drag-and-drop operations.

How CyberChef Works — The "Recipe" Concept

  1. You paste your input data (text or file) into the "Input" panel
  2. You drag operations from the left panel into the "Recipe" (middle)
  3. Operations run in order — output of one becomes input of next
  4. Result appears in the "Output" panel — instantly
  5. You can save/load recipes as JSON for reuse

What CyberChef Can Do (400+ Operations)

  • Encoding — Base64, Base32, Hex, URL, HTML, JWT, ROT13

  • Compression — Gzip, Zip, Bzip2, LZMA, Bz2

Real-World Use Cases

1. Malware Analysis

Malware often uses base64, XOR, or custom encoding. CyberChef decodes payloads step-by-step. Deobfuscate PowerShell, JavaScript, VBA macros.

Every CTF has encoding/crypto challenges. CyberChef solves them instantly — base64, ROT, XOR, Vigenère, RSA, etc.

3. Incident Response

Analyze suspicious logs, decode JWT tokens, parse PCAP data, extract IOCs from text.

4. Threat Intelligence

Decode malware configs, extract C2 domains from obfuscated strings, parse YARA rules.

5. Forensics

Analyze network captures, decode encoded payloads, extract metadata from files.

6. Web Dev / Debugging

Decode JWTs, parse cookies, inspect URLs, convert JSON/YAML/XML.

7. Password Cracking

Generate hashes to compare, encode/decode wordlists, transform passwords.

8. Data Analysis

Convert data formats, extract patterns, clean logs, parse CSVs.

Complete Workflow — Malware Analysis
Step 1: Open CyberChef
Visit gchq.github.io/CyberChef or use offline version.
Step 2: Paste Obfuscated Payload
Copy suspicious string from malware sample into input panel.
Step 3: Add "Magic" Operation
Drag "Magic" from Operations — CyberChef auto-detects encoding.
Step 4: Review Detected Operations
Magic will identify: Base64, XOR, gzip, etc. Click to apply.
Step 5: Manually Chain Operations
If Magic fails, add operations one at a time: From Base64 → XOR → Gunzip.
Step 6: Extract IOCs
Add Extract IPs, Extract URLs, Extract Emails to get indicators.
Step 7: Save Recipe
Click "Save recipe" — get JSON. Load it later for similar samples.
Step 8: Export Result
Copy decoded payload, download as file, or bake into new recipe.

Troubleshooting

"Output doesn't make sense"

  • Try "Magic" operation — auto-detects encoding
  • Wrong encoding? Try UTF-8, UTF-16LE, Latin-1
  • Data might need multiple layers — chain operations

"XOR doesn't work"

  • XOR needs the correct key — try common keys: 0x01, 0x41, 0xFF
  • Try "XOR Brute Force" to find the key
  • Multi-byte key: use "XOR with key" and enter key in hex

"File won't load"

  • CyberChef handles files up to ~100MB (browser limitation)
  • Try loading in chunks
  • For huge files, use offline version with more memory

"Recipe too slow"

  • Disable auto-bake
  • Remove unnecessary operations
  • Use "Fork" to process data in parallel

"Can't find operation"

  • Search in top-left search box
  • Operations organized by category on left sidebar
  • Try similar operation names (e.g., "b64" → "From Base64")

"Offline version opens but operations missing"

  • Download latest version — older versions have fewer ops
  • Clear browser cache
  • Check console (F12) for errors
