What is Hashcat? (Deep Theory)

Hashcat is a highly optimized GPU-based password cracker that tests billions of candidate passwords against target hashes per second. Unlike CPU-bound tools like John the Ripper, hashcat leverages GPU parallelization for massive speedup.

How Hashcat Works

  • GPU Acceleration — Each GPU core runs thousands of hash computations in parallel
  • Hash Modes (-m flag) — Maps to specific algorithms (MD5=-m0, SHA1=-m100, bcrypt=-m3200, etc.)
  • Attack Modes (-a flag) — Dictionary (0), Combination (1), Brute-force (3), Hybrid (6/7), Mask (3), Rule-based (0+r), etc.
  • Wordlists & Rules — Feed candidate words, apply transformations, generate patterns
  • Candidate Generation — Creates passwords on-the-fly (no pre-gen needed for brute-force)

Why Hashcat Dominates

  • Speed — 10-100x faster than CPU tools for supported algorithms
  • Support — 350+ hash types (MD5, SHA, bcrypt, NTLM, WPA, PDF, Office, etc.)
  • Attack Flexibility — Dictionary, brute-force, mask, hybrid, rule-based, and custom combos
  • Resource Efficient — Use GPU, keep CPU free for other tasks
  • Benchmark Mode — Test crack speed before committing time
  • Session Management — Pause/resume long cracks, checkpoints
  • Active Development — Regularly updated with new features and hash types

GPU vs CPU Performance

  • MD5 on GPU — ~100 GH/s (billion hashes/sec) vs ~500 MH/s on CPU = 200x faster
  • SHA1 on GPU — ~50 GH/s vs ~100 MH/s on CPU = 500x faster
  • bcrypt on GPU — ~100 KH/s (thousand hashes/sec) vs single-digit H/s on CPU = massive gap
  • Trade-off — bcrypt/Argon2 are intentionally memory-hard to prevent GPU acceleration
💡
Key Insight: Hashcat doesn't "crack" passwords in the traditional sense—it generates candidates and compares hashes at GPU speeds. Fast hashes (MD5, SHA1) crack in minutes. Slow hashes (bcrypt, Argon2) stay secure even with GPU power.

Basic Usage & Core Commands
1. Check Version & Available Devices
hashcat --version
2. List All Hash Modes (-m reference)
hashcat -h | grep "^[ ]*0 " -A 100 | head -50
3. List Attack Modes
hashcat -h | grep "^Attack mode"
4. Benchmark Hash Mode
Test cracking speed before starting full attack.
hashcat -b -m 0
Speed bench for MD5 hash mode
5. Dictionary Attack (MD5)
Try every word in wordlist against hashes.
hashcat -m 0 -a 0 hashes.txt wordlist.txt
6. Dictionary Attack with Rules
Apply transformations to wordlist words.
hashcat -m 0 -a 0 hashes.txt wordlist.txt -r rules/best64.rule
7. Brute-Force Attack (8-char lowercase)
Try all combinations of lowercase letters + numbers.
hashcat -m 0 -a 3 hashes.txt ?l?l?l?l?l?l?l?l
8. Brute-Force with Charset
Custom character set (uppercase + lowercase + numbers).
hashcat -m 0 -a 3 hashes.txt -1 ?u?l?d ?1?1?1?1?1?1?1?1
9. Hybrid Attack (Dictionary + Mask)
Append mask pattern to every wordlist word.
hashcat -m 0 -a 6 hashes.txt wordlist.txt ?d?d?d?d
10. Combination Attack
Combine two wordlists (word1 + word2).
hashcat -m 0 -a 1 hashes.txt wordlist1.txt wordlist2.txt
11. Reverse Hybrid (Mask + Dictionary)
Prepend mask pattern to wordlist words.
hashcat -m 0 -a 7 hashes.txt ?d?d?d?d wordlist.txt
12. Single Hash Crack
Crack one hash directly.
hashcat -m 0 '5d41402abc4b2a76b9719d911017c592' wordlist.txt
13. Show Cracked Passwords
hashcat -m 0 hashes.txt --show
14. Save Results to File
hashcat -m 0 hashes.txt wordlist.txt -o cracked.txt
15. Cracking with Specific Device
hashcat -m 0 hashes.txt wordlist.txt -d 1
16. Multiple Devices/GPUs
hashcat -m 0 hashes.txt wordlist.txt -d 1,2
17. Workload Profile (Optimization)
1=light, 2=default, 3=high, 4=nightmare (risk GPU crash).
hashcat -m 0 hashes.txt wordlist.txt -w 3
18. Pause & Resume (Session)
hashcat -m 0 hashes.txt wordlist.txt -S session_name # Resume: press 's' during run, or: hashcat -m 0 hashes.txt wordlist.txt -S session_name --restore
19. Incremental Mode (Brute-Force by Length)
hashcat -m 0 -a 3 hashes.txt ?l --increment --increment-min 4
20. Limit Guesses/Time
hashcat -m 0 hashes.txt wordlist.txt --limit 1000000

29. Loopback Attack (Crack as Word)
Reuse cracked passwords as input for further attacks.

30. Custom Charset Definition
Define custom character sets for brute-forcing.

31. Mask Attack (Common Patterns)
?u=upper, ?l=lower, ?d=digit, ?s=special, ?a=all.
hashcat -m 0 -a 3 hashes.txt ?u?l?d?d?d # Password1993 hashcat -m 0 -a 3 hashes.txt ?d?d?d?d?d?d?d?d # 12345678 (all numbers) hashcat -m 0 -a 3 hashes.txt ?l?l?l?l?s # test! (word + special)
32. Apply Multiple Rules to Wordlist
Chain multiple rules together.
hashcat -m 0 hashes.txt wordlist.txt -r rule1.rule -r rule2.rule
33. Generate Rules On-The-Fly
hashcat -m 0 hashes.txt wordlist.txt -g 1000
34. Output Format Options
Hash:Pass format, or just plain text.
hashcat -m 0 hashes.txt wordlist.txt -o results.txt --outfile-format 3
35. Pot File (Automatic Tracking)
Hashcat saves all cracked hashes to hashcat.pot.
cat hashcat.pot # View all previous cracks hashcat -m 0 hashes.txt wordlist.txt --show # Show any pre-cracked hashes
36. Disable Pot File (Privacy)
hashcat -m 0 hashes.txt wordlist.txt --potfile-disable
37. Quiet Mode (No Output)
hashcat -m 0 hashes.txt wordlist.txt -q
38. Status Update Interval
hashcat -m 0 hashes.txt wordlist.txt -u 10 # Update every 10 seconds
39. Identify Hash Mode Auto
hashcat --identify 5d41402abc4b2a76b9719d911017c592
40. Verify Cracked Password Manually
echo -n "password" | md5sum # Compare with original hash

Performance Optimization Tips

1. Use GPU Not CPU

  • Always ensure GPU drivers installed: nvidia-smi or rocm-smi
  • CPU fallback is 100x slower

2. Workload Profile

  • -w 1 = light (can multitask)
  • -w 2 = default (balanced)
  • -w 3 = high (GPU 100%, hang risk)
  • -w 4 = nightmare (GPU crash risk)

3. Multiple GPUs

  • -d 1,2,3 = use GPUs 1, 2, and 3 simultaneously
  • Scales nearly linearly with GPU count

4. Optimize Attack Mode

  • Dictionary (slowest word check) < Hybrid < Mask < Brute-force (generates on-fly)
  • Mask attacks generate candidates on GPU (faster than CPU wordlist I/O)

5. Wordlist Quality

  • rockyou.txt (14 MB) covers 80% of weak passwords
  • Larger wordlists = slower scanning but better coverage

6. Rules Matter

  • best64.rule captures common transformations
  • nsa64.rule = more aggressive
  • Multiple rules compound: -r rule1.rule -r rule2.rule

7. Session Management for Long Runs

  • Don't let GPU run 24/7 → heat damage
  • Use -S session_name --restore to pause/resume

8. Benchmarking

  • Always benchmark first: hashcat -b -m [mode]
  • Estimate time to crack: speed × dictionary size
Troubleshooting & Common Issues

GPU Not Recognized

  • Install GPU drivers: NVIDIA CUDA or AMD HIP
  • Check: hashcat -I
  • If CPU-only fallback: hashcat: /usr/local/cuda/lib64: cannot open shared object → install CUDA

Slow Performance (Using CPU)

  • Hashcat fell back to CPU (drivers missing)
  • Install correct GPU drivers for your hardware

Hash Not Cracking

  • Wrong hash mode? Use hashcat --identify
  • Wrong wordlist? Try rockyou.txt or larger dictionary
  • Password too complex? Try brute-force or rules

Out of Memory Error

  • GPU VRAM full → reduce workload: -w 1 or -w 2
  • Or use smaller wordlist

Hash Format Not Recognized

  • Double-check format with hash-identifier
  • Some hashes need prefix (e.g., $1$salt$hash for MD5 crypt)

Cracking Takes Too Long

  • Hash type slow? (bcrypt = intentionally slow)
  • Try simpler attacks first: dictionary → hybrid → mask
  • Use rules to reduce candidate count

Can't Resume Session

  • Session file lost? Try without --restore
  • Or restart attack from scratch with same parameters
