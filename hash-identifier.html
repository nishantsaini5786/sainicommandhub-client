Hash-Identifier is your first step in password cracking. Given a hash string, it identifies the algorithm (MD5, SHA1, SHA256, bcrypt, etc.) using pattern matching, length analysis, and entropy calculation. It's completely passive — no brute-force, no network traffic, just pattern recognition. Hash-Identifier is essential for every penetration tester and CTF player.

What is Hash-Identifier? (Deep Theory)

Hash-Identifier is a Python tool that analyzes hash strings and determines their type. Once you know the hash type, you can choose the right cracking tool (hashcat, john, online services, etc.).

How It Works Internally

  • Length Analysis — Different algorithms produce different output lengths (MD5 = 32 chars, SHA1 = 40, SHA256 = 64, etc.)
  • Character Analysis — Some hashes are hex-only, some include special chars (bcrypt uses $2a$)
  • Pattern Matching — Recognizes prefixes/suffixes ($1$, $2a$, $apr1$, etc.)
  • Entropy & Format — Calculates randomness and checks for known formats

Why Hash-Identifier is Essential

  • Saves Time — Don't waste hours testing the wrong cracking tool
  • Multiple Possibilities — One hash length can match multiple algorithms; identifier ranks them by probability
  • Prepares Your Attack — Know the algorithm → Choose the right wordlist, rules, and hardware
  • CTF Essential — First tool in any CTF password cracking challenge
  • Penetration Testing — When you find password hashes, identify them first

Advanced Techniques & Analysis
13. Analyze Hash Length Pattern
Quick identification by length alone.
32 chars hex = MD5/NTLM 40 chars hex = SHA1 64 chars hex = SHA256 128 chars hex = SHA512
14. Identify by Prefix/Format
Many hashes have distinctive prefixes.
$2a$ or $2b$ = bcrypt $1$ = MD5 (Unix) $5$ = SHA256 (Unix) $6$ = SHA512 (Unix) $apr1$ = Apache MD5 $argon2$ = Argon2
15. Manual Analysis Tools
Combine hash-identifier with manual checks.
echo -n "test" | md5sum # Generate MD5 for comparison echo -n "test" | sha1sum # Generate SHA1 echo -n "test" | sha256sum # Generate SHA256
16. Check Against Known Values
Test if hash is "hello" (common test value).
MD5("hello") = 5d41402abc4b2a76b9719d911017c592 SHA1("hello") = aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d SHA256("hello") = 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
17. Salted Hash Identification
Identify if hash includes salt (often mixed in).
18. Identify Hash Rounds (Work Factor)
bcrypt/argon2 hashes include cost factors.
$2a$12$ = bcrypt with 12 rounds (2^12 = 4096 iterations) $2b$04$ = bcrypt with 4 rounds (faster but weaker) Higher rounds = harder to crack
19. Identify Keyed Hashes (HMAC)
HMAC-MD5, HMAC-SHA1 used in tokens/APIs.
Format: HMAC(algorithm, message, key) Example: HMAC-MD5("message", "secret_key") Identified by: Context and known algorithm patterns
20. Identify WordPress/PHP Hashes
WordPress uses MD5 or phpass (portable PHP).
$P$B... = WordPress phpass hash wp_signon() uses phpass for security Cracker-friendly targets
21. Identify Apache Hashes
$apr1$ = Apache MD5 $2y$ = Apache bcrypt htpasswd -c .htpasswd user (creates these)
22. Check Character Set (Hex vs Binary)
Hex hashes use 0-9, a-f only.
Hex-only = Standard hash (MD5, SHA1, SHA256, etc.) With $, numbers = Salted format (bcrypt, Unix shadow) Uppercase = Might be base64 or different encoding
23. Identify Scrypt/Argon2 Hashes
Modern password hashing (memory-hard).
$scrypt$params$salt$hash = scrypt format $argon2i$ or $argon2d$ = Argon2 format Very hard to crack (memory requirements)
24. Quick Online Lookup
Some hashes are rainbow-table hits.
Google: [hash] md5 MD5 Online: https://md5.gromweb.com/?md5=[hash] CrackStation: https://crackstation.net/ Caution: Privacy risk if value is sensitive
25. Use hashcat -m Flag Reference
Map identified hash to hashcat mode number.
hashcat -m 0 = MD5 hashcat -m 100 = SHA1 hashcat -m 1400 = SHA256 hashcat -m 3200 = bcrypt hashcat -m 1800 = SHA512 hashcat -h | grep -i algorithm
Common Hash Types Deep Dive
26. MD5 - Fast But Broken
32 hex chars. Cryptographically broken, collision-prone.
Length: 32 hex characters Speed: Very fast to crack Risk: Weak (legacy systems only) Example: 5d41402abc4b2a76b9719d911017c592 Crack with: hashcat -m 0, john, online services
27. SHA1 - Deprecated
40 hex chars. Also broken, collision found in 2017.
Length: 40 hex characters Speed: Fast to crack Risk: Weak (don't use for new systems) Example: aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d Crack with: hashcat -m 100, john
28. SHA256 - Industry Standard
64 hex chars. Cryptographically secure (for now).
Length: 64 hex characters Speed: Moderate (GPU acceleration needed at scale) Risk: Currently secure (no known collisions) Example: 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824 Crack with: hashcat -m 1400, john (slow)
29. bcrypt - Industry Gold Standard
60 chars with $2a$ prefix. Salted & adaptive cost.
Length: 60 characters (22 char salt + hash) Format: $2a$12$salt$hash or $2b$ or $2y$ Speed: Intentionally slow (work factor) Risk: Very hard to crack (still secure) Cost: $2a$12$ = 2^12 iterations (adaptive) Crack with: hashcat -m 3200, john (very slow)
30. NTLM - Windows Legacy
32 hex chars. Windows password hashes.
Length: 32 hex characters (looks like MD5) Format: Unicode uppercase, DES-based Speed: Fast but specialized tools needed Risk: Moderate (pass-the-hash attacks work) Found in: Windows SAM, LSASS dumps Crack with: hashcat -m 1000, john
31. LM Hash - Ancient
32 hex chars. DES-based, VERY weak.
Length: 32 hex characters Format: aad3b435b51404eeaad3b435b51404ee (empty password default) Speed: Can be cracked in hours with rainbow tables Risk: Critically weak (don't use) Found in: Very old Windows systems Crack with: Rainbow tables, hashcat -m 3000
32. Argon2 - Future Proof
Memory-hard, adaptive, very slow to crack.
Format: $argon2i$ or $argon2d$ Speed: VERY slow (memory requirements) Risk: Extremely hard to crack (future-proof) Memory: Uses significant RAM during hashing Crack with: hashcat -m 2500 (with GPU limits), john Best for: New applications
33. SHA512 (Unix Shadow)
128 hex chars. Also $6$ prefix format.
Length: 128 hex characters (or $6$ format) Format: $6$salt$hash Speed: Slow (more rounds than SHA256) Risk: Currently secure Found in: /etc/shadow files Crack with: hashcat -m 1800, john
34. MD5 (Unix Shadow) - $1$
Format: $1$salt$hash Speed: Moderate (multiple rounds) Risk: Weak (MD5 is broken) Found in: Older Linux systems Crack with: hashcat -m 500, john
35. SHA256 (Unix Shadow) - $5$
Format: $5$salt$hash Speed: Moderate to slow Risk: Secure Found in: Modern Linux systems Crack with: hashcat -m 7400, john

Troubleshooting & Tips

Hash-Identifier Shows Multiple Matches

  • Length ambiguity (32 chars = MD5, NTLM, or others)
  • Look at context (Windows = likely NTLM; Linux = likely MD5 or SHA)
  • First match is usually most probable

Hash Not Recognized

  • Check hash format (might be base64, not hex)
  • Remove any $ prefixes and analyze the core hash
  • Verify character set (should be hex, alphanumeric, or specific format)
  • Length might be off (copy-paste errors)

Too Generic Results

  • Use hashcat --identify for more precise detection
  • Cross-reference with source (Windows SAM = NTLM, /etc/shadow = Unix format)
  • Look for distinctive prefixes ($2a$, $1$, $6$, etc.)

Non-Interactive Mode Needed

  • Pipe input: echo "hash" | python3 hash-identifier.py
  • Or use hashcat's identify feature for scripting

Command Not Found

  • Install: sudo apt install hash-identifier
  • Or: git clone https://github.com/blackploit/hash-identifier.git
  • Run with: python3 hash-identifier.py

Unicode/Encoding Issues

  • Hash-identifier expects ASCII/hex
  • If hash is base64, decode first: echo "base64hash" | base64 -d | xxd
Pro Tips & Best Practices

Always Identify First

Never guess the hash type. Identifying wrong = wasted hours on wrong cracker/wordlist.

Combine with Hashcat --identify

For more precise identification: hashcat --identify hash.txt

Consider Context

Where was the hash found? Windows SAM = NTLM. Linux /etc/shadow = MD5, SHA256, or SHA512. Database = depends on DB type.

Look at Rounds/Cost Factor

Higher bcrypt cost = longer crack time. $2a$12$ is harder than $2a$04$.

Use Mode Numbers in Hashcat

After identification, map to hashcat -m number for optimal performance.

Combine Tools for Batch Analysis

Loop through extracted hashes and identify all before prioritizing cracking.

Privacy First

Don't send sensitive hashes to online tools. Use local hash-identifier or hashcat.
