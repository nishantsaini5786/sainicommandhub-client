Binwalk is a fast, easy-to-use tool for analyzing, reverse engineering, and extracting firmware images. It scans binary files for embedded files, file systems, compressed archives, and executable code. If you're into IoT security, router hacking, or firmware analysis — Binwalk is your go-to tool.

What is Binwalk? (Deep Theory)

Firmware images (like those from routers, cameras, IoT devices) are usually concatenated blobs — bootloader + kernel + rootfs + config files all packed together. You can't just open them in a text editor and understand what's inside.

Binwalk solves this. It uses a database of magic signatures (file headers) to find embedded content, then extracts each piece.

What Binwalk Detects

  • Compressed archives — gzip, bzip2, xz, LZMA, ZIP
  • File systems — SquashFS, CramFS, JFFS2, ext2/3/4, UBIFS
  • Executables — ELF binaries, PE executables
  • Bootloaders — U-Boot, GRUB, RedBoot
  • Certificates — X.509, RSA keys
  • Kernel images — Linux kernel, compressed kernel
  • Device trees — DTB files
  • Images — PNG, JPEG, GIF within firmware
  • Encryption signatures — AES keys, RSA keys
  • Custom signatures — you can add your own

Entropy Analysis

Binwalk can also perform entropy analysis — measuring randomness in the binary. High entropy = encrypted or compressed. Low entropy = plain text/data. This helps identify where encrypted sections begin.

Why it matters: Before hacking an IoT device, you need to understand what's inside its firmware. Binwalk reveals everything — file systems, binaries, config files, credentials.
Real-World Use Cases

1. IoT Device Hacking

Extract firmware from a smart camera, router, or thermostat. Find hardcoded credentials and backdoors.

2. Router Firmware Analysis

Download router firmware from vendor site, analyze with Binwalk, find vulnerabilities before attackers do.

3. Malware Analysis

Malware often hides additional payloads inside its binary. Binwalk reveals embedded droppers and stages.

4. CTF Forensics

Challenges often involve files with hidden content — Binwalk reveals flags hidden in images or firmware.

5. Reverse Engineering

Extract SquashFS from firmware and analyze binaries with Ghidra/IDA.

6. Security Audit

Vendors can audit their own firmware for accidental inclusion of private keys or debug code.

7. Data Recovery

Recover files from corrupted disk images or memory dumps.

Installation

Kali Linux / Debian / Ubuntu

sudo apt update && sudo apt install -y binwalk

Install Extraction Dependencies

sudo apt install -y squashfs-tools mtd-utils zlib1g-dev liblzma-dev

Alternative: Rust Version (Fast)

cargo install binwalk

Verify

binwalk --help
Binwalk v2.3.4 Usage: binwalk [OPTIONS] [FILE1] [FILE2] [FILE3] ...
Basic Commands
1. Basic Scan
Scan firmware for embedded signatures.
binwalk firmware.bin
DECIMAL HEXADECIMAL DESCRIPTION -------------------------------------------------------------------------------- 0 0x0 uImage header, header size: 64 bytes 1024 0x400 LZMA compressed data 2949120 0x2D0000 Squashfs filesystem, little endian, version 4.0 8192000 0x7D0000 JFFS2 filesystem, little endian
2. Extract Embedded Files
Auto-extract all discovered files.
binwalk -e firmware.bin
Extracted to _firmware.bin.extracted/ ├── 400 ├── 400.lzma ├── 2D0000.squashfs └── 7D0000.jffs2
3. Recursive Extraction
Extract, then extract what's inside extracted files too.
binwalk -Me firmware.bin
4. Entropy Analysis
Visual entropy graph — high points = encrypted/compressed.
binwalk -E firmware.bin
Entropy graph saved: firmware.bin.png High entropy regions: 0x400-0x2D0000 (compressed) Low entropy regions: 0x0-0x400 (headers)
5. Detailed Signature Match
Show raw signature data — verbose output.
binwalk -W firmware.bin
6. Scan with All Signatures
binwalk -y firmware.bin
7. Raw Scan (Search for Strings)
binwalk -R "\x89PNG" firmware.bin
Advanced Scanning
8. Specific Signature Type
Only look for SquashFS filesystems.
binwalk -y squashfs firmware.bin
9. Include Specific Signature
binwalk -y "gzip" -y "squashfs" firmware.bin
10. Exclude Signature Type
binwalk -x "png" -x "jpg" firmware.bin
11. Extract to Custom Directory
binwalk -e -C /path/to/output firmware.bin
12. Extract Specific Offset
Extract from a specific offset only.
binwalk -e -o 2949120 firmware.bin
13. Show File Hashes
binwalk -H firmware.bin
14. MD5 Hash
binwalk -M firmware.bin
15. SHA256 Hash
binwalk -S firmware.bin
Signature Management
16. Update Signatures
Fetch latest signature database.
binwalk --update
17. List All Signatures
binwalk -L
18. Show Extraction Rules
binwalk --list
19. Only Extract (No Scan)
binwalk --dd=".*" firmware.bin
20. Custom Signature File
binwalk -c custom-magic-file firmware.bin
Extraction Options
21. Extract Gzip Only
binwalk --dd='gzip:gz' firmware.bin
22. Extract SquashFS Only
binwalk -e --include=squashfs firmware.bin
23. Extract to STDERR (Streaming)
binwalk -e --dd='.*' --preserve-symlinks firmware.bin
Complete Workflow — Firmware Analysis
Step 1: Download Firmware
Get firmware from vendor site or extract from device (via UART/JTAG/flash dump).
Step 2: Initial Scan
binwalk firmware.bin
Identify components: header, kernel, rootfs, config.
Step 3: Entropy Analysis
binwalk -E firmware.bin
Check for encrypted regions (high entropy).
Step 4: Extract Everything
binwalk -Me firmware.bin
Recursive extraction gets nested archives too.
Step 5: Explore Extracted Files
cd _firmware.bin.extracted/ && ls -la
Look for SquashFS, JFFS2, or other filesystems.
Step 6: Mount Filesystem
If SquashFS extracted:
unsquashfs 2D0000.squashfs
Step 7: Search for Secrets
grep -r "password" squashfs-root/ 2>/dev/null
Step 8: Analyze Binaries
Look for ELF binaries and analyze with Ghidra, radare2, or strings.
find . -type f -exec file {} \; | grep ELF
Step 9: Check for Hardcoded Creds
grep -r "admin\|root\|password\|api_key" squashfs-root/etc/ 2>/dev/null
Step 10: Document Findings
Save all credentials, scripts, and interesting binaries for report.

Troubleshooting

"No signatures found"

  • Try raw scan: binwalk -R "squashfs" firmware.bin
  • Update signatures: binwalk --update
  • File might be encrypted — check entropy

"Extraction failed"

  • Install dependencies: sudo apt install squashfs-tools mtd-utils
  • Try manual extraction with specific tools
  • Check if file is corrupted

"Entropy analysis crashes"

  • Needs Python matplotlib: pip install matplotlib
  • Try binwalk -E --save

"Recursive extraction takes too long"

  • Limit depth: -M only goes a few levels
  • Extract specific offset only
  • Cancel with Ctrl+C — partial extraction still useful

"SquashFS won't mount"

  • Try unsquashfs -f file.squashfs
  • Install latest squashfs-tools
  • Check if it's a modified SquashFS variant

"Permission denied on extraction"

  • Run from a directory you own
  • Check disk space
  • Use -C to specify writable output
