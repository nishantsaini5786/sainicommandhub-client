BETTERCAP
Network · MITM Attack Framework
Advanced 35+ Commands MITM WiFi BLE

Bettercap is a powerful, modular, and portable framework for WiFi, Bluetooth Low Energy, HID, and Ethernet reconnaissance and MITM attacks. It replaces and modernizes tools like Ettercap, ARP poisoning scripts, and WiFi attack frameworks with a single, extensible, cross-platform tool. Written in Go, it's fast, modern, and loved by red teams.

What is Bettercap? (Deep Theory)

Bettercap is a modern Swiss-army knife for network attacks. It replaces several older tools:

  • Ettercap → ARP/DNS spoofing, MITM
  • arpspoof → ARP poisoning
  • aireplay-ng → WiFi deauth
  • mitmproxy → HTTP/HTTPS interception
  • Responder → LLMNR/NBT-NS/mDNS poisoning

Why Bettercap is Better

  • Single binary — no dependency hell
  • Modular — enable/disable capabilities on the fly
  • Interactive shell — command-driven like Metasploit
  • Web UI — accessible from browser (bettercap -caplet http-ui)
  • Cross-platform — Linux, macOS, Windows, Android
  • Scriptable — caplets for automation
  • Modern protocols — BLE, HID, WiFi (2.4 + 5GHz), Ethernet

What Bettercap Can Do

  • Network recon — discover hosts, devices, services
  • ARP spoofing — MITM between victim and gateway
  • DNS spoofing — redirect domains to fake IPs
  • HTTP/HTTPS proxy — intercept, modify, inject
  • SSL stripping — downgrade HTTPS to HTTP
  • WiFi recon — scan APs and clients
  • WiFi deauth — disconnect clients
  • BLE scanning — discover Bluetooth devices
  • HID attacks — via USB Rubber Ducky-like devices
  • Credential sniffing — capture HTTP auth, cookies, POST data

Troubleshooting

"No WiFi interface found"

  • WiFi adapter missing or driver issue
  • Use sudo airmon-ng start wlan0 first
  • Check adapter supports monitor mode

"ARP spoof not working"

  • Check IP forwarding: sysctl net.ipv4.ip_forward
  • Enable: sudo sysctl -w net.ipv4.ip_forward=1
  • Ensure victim and gateway are on same subnet

"SSL strip not capturing"

  • Modern sites use HSTS — hard to bypass
  • Try HTTP-only sites for demos
  • Some browsers preload HSTS lists

"Web UI not loading"

  • Check port: netstat -tlnp | grep :80
  • Firewall blocking? sudo ufw allow 80
  • Try http://127.0.0.1:80

"Deauth not working"

  • Adapter must support packet injection
  • Target must be on same channel
  • Some APs have deauth protection (802.11w)

"Permission denied"

  • Bettercap needs root for most operations
  • Always run with sudo
