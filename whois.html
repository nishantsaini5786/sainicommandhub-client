🧠 WHAT IS WHOIS?

WHOIS is a TCP-based query/response protocol historically used to provide registration and allocation information. A WHOIS client sends a text query to a server and receives human-readable text. The protocol uses TCP port 43. Modern registration-data services can differ by registry, registrar, and policy, so a response is not guaranteed to contain every field you expect.

DOMAIN / IP→WHOIS CLIENT→SERVER : 43→TEXT RESPONSE
🎯 WHAT CAN YOU LEARN?

DOMAIN

Registrar, status, nameservers, creation/update/expiry fields and registry/registrar references when publicly returned.

IP / NETWORK

Allocation organization, netname, CIDR, country, route and contact fields when supplied by the relevant service.

OSINT WORKFLOW

Use WHOIS as one source, then validate findings with DNS, certificate transparency, HTTP, ASN and other authoritative sources.

🔬 PRACTICAL RECON WORKFLOW
  1. Start with a domain or IP that you own or are authorized to investigate.
  2. Run a basic WHOIS query and save the raw response.
  3. Extract registrar, status, nameserver, lifecycle and network fields.
  4. Correlate nameservers with DNS records and certificates.
  5. For IPs, correlate CIDR/ASN/organization information with routing data.
  6. Record the collection date because registration data can change.
  7. Validate important findings with an independent authoritative source.
⚠️ IMPORTANT LIMITATIONS

WHOIS is not a guaranteed source of complete identity information. Privacy services, redaction, registry policies, rate limits, referrals and differing response formats can remove or alter fields. Do not treat a WHOIS field as proof of ownership or identity without independent verification.

Use WHOIS responsibly and only for domains, IPs and networks you are authorized to investigate. Avoid high-volume querying that could violate service policies.

🧩 TROUBLESHOOTING

Command not found

Install the whois package and verify with command -v whois.

No useful data

Try the relevant registry/WHOIS server and remember that some services return limited or redacted data.

Timeout / failure

Check DNS/network connectivity, TCP port 43 reachability and server-side rate limits.
