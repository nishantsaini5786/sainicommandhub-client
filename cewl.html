CEWL
Password / Auth · Custom Wordlist Generator
Beginner 20+ Commands Wordlist Spider OSINT

CeWL (Custom Word List generator) is a Ruby application that spiders a target website and creates a custom wordlist of unique words found on its pages. This wordlist is then used for password cracking — because people often use words from their own website, company name, or personal interests as passwords. CeWL is a must-have for any password audit or red team engagement.

What is CeWL? (Deep Theory)

Traditional password cracking uses generic wordlists like rockyou.txt. But these fail if the target's password is specific to their life or business — like the company name, CEO's name, or product name.

CeWL solves this by scraping the target's website for meaningful words. Then it uses those words (plus variations) as a custom wordlist.

How CeWL Works

  1. Given a URL, CeWL crawls the entire website (up to configured depth)
  2. It extracts all visible text from HTML pages, PDFs, and metadata
  3. Filters out short words, numbers, and common stop-words
  4. Saves unique words to an output file
  5. Optionally generates email addresses from discovered names

What CeWL Can Extract

  • Page content — visible text on HTML pages
  • Meta tags — keywords, description, author
  • PDF files — with --pdf flag
  • Email addresses — with -e flag
  • Word lengths — filter by minimum word length
  • Word counts — filter by frequency

Why CeWL is Powerful

  • Passwords like Company2024! or ProductName@123 won't be in rockyou.txt
  • CeWL generates these from the target's own site
  • Combined with rules (hashcat, john), it's extremely effective
  • Used in every serious password audit
💡
Real-world example: A company uses "TechCorp" everywhere. CeWL scrapes their site and gets words like "TechCorp", "Innovate", "Solutions2024". Combined with hashcat rules, it cracks 40% more passwords than rockyou.txt alone.

Basic Commands
1. Basic Wordlist Generation
Scrape site and save all unique words to output file.
cewl https://example.com -w wordlist.txt
CeWL 5.5.2 (Grouping) Robin Wood Spidering: https://example.com Finished in 12.3 seconds Wordlist written to wordlist.txt (847 unique words)
2. Show Words on Screen (No File)
cewl https://example.com
3. Specify Crawl Depth
Follow links N levels deep. Default is 2.
cewl https://example.com -d 3 -w wordlist.txt
4. Minimum Word Length
Only include words with 8+ characters.
cewl https://example.com -m 8 -w wordlist.txt
5. Lowercase All Words
cewl https://example.com --lowercase -w wordlist.txt
6. Include Meta Data
Include meta keywords, description, author tags.
cewl https://example.com -a -w wordlist.txt
7. Include Email Addresses
Harvest emails found on the site.
cewl https://example.com -e -w wordlist.txt
8. Specify User Agent
cewl https://example.com -u "Mozilla/5.0 (X11; Linux)" -w wordlist.txt
9. Random User Agent
cewl https://example.com --random-user-agent -w wordlist.txt
10. Delay Between Requests
Slow down to avoid detection/rate-limiting.
cewl https://example.com --delay 2 -w wordlist.txt
Advanced Commands
11. Include PDF Files
Extract words from PDFs found on the site.
cewl https://example.com --pdf -w wordlist.txt
12. Include Document Metadata
cewl https://example.com --meta -w wordlist.txt
13. Include Author Names
cewl https://example.com --author -w wordlist.txt
14. Include Page Title
cewl https://example.com --title -w wordlist.txt
15. Include Meta Description
cewl https://example.com --desc -w wordlist.txt
16. Include Meta Keywords
cewl https://example.com --meta_keywords -w wordlist.txt
17. Extract Emails to Separate File
cewl https://example.com -e --email_file emails.txt -w wordlist.txt
18. HTTP Authentication
For sites behind Basic auth.
cewl https://example.com --auth_type basic --auth_user admin --auth_pass password -w wordlist.txt
19. Custom Cookie
cewl https://example.com --cookie "session=abc123" -w wordlist.txt
20. Custom Headers
cewl https://example.com --header "X-Custom: value" -w wordlist.txt
21. Use Proxy
cewl https://example.com --proxy_host 127.0.0.1 --proxy_port 8080 -w wordlist.txt
22. Skip SSL Verification
For sites with self-signed certificates.
cewl https://example.com --no-verify-ssl -w wordlist.txt
23. Count Occurrences
Generate wordlist with word count (useful for stats).
cewl https://example.com --count -w wordlist.txt
24. Custom User Agent File
cewl https://example.com --user_agent_file agents.txt -w wordlist.txt
25. Save Debug Output
cewl https://example.com --debug -w wordlist.txt
Using CeWL Output — Password Cracking
26. Crack with John the Ripper
Use CeWL-generated wordlist with John.
john --wordlist=cewl-wordlist.txt hashes.txt
27. Crack with Hashcat
hashcat -m 0 -a 0 hashes.txt cewl-wordlist.txt
28. Combine with RockYou
Merge CeWL list with rockyou for maximum coverage.
cat cewl-wordlist.txt /usr/share/wordlists/rockyou.txt | sort -u > combined.txt
29. Add Hashcat Rules
Expand CeWL list with rules (append numbers, capitalize, etc.).
hashcat -m 0 -a 0 hashes.txt cewl-wordlist.txt -r /usr/share/hashcat/rules/best64.rule
30. Crack WPA Handshake
Use CeWL list with aircrack-ng for WiFi passwords.
aircrack-ng -w cewl-wordlist.txt capture.cap
Complete Workflow — Password Audit
Step 1: Identify Target
Choose target company's public website (e.g., company.com).
Step 2: Scrape Site with CeWL
cewl https://company.com -d 3 -m 5 -a -e --with-numbers -w company-wordlist.txt
Step 3: Review Wordlist
wc -l company-wordlist.txt && head -20 company-wordlist.txt
Step 4: Merge with RockYou
cat company-wordlist.txt /usr/share/wordlists/rockyou.txt | sort -u > final-wordlist.txt
Step 5: Apply Rules (Transformations)
Use hashcat rules to generate variants: Company → Company123, C0mpany!
hashcat --stdout company-wordlist.txt -r /usr/share/hashcat/rules/best64.rule > expanded.txt
Step 6: Crack Hashes
hashcat -m 1000 -a 0 hashes.txt expanded.txt
Step 7: Analyze Results
Document which passwords were cracked and identify patterns.
Step 8: Report Findings
Report: "X% of employee passwords were company-specific terms found on the website."

Troubleshooting

"No words found"

  • Site might be JavaScript-rendered (SPA) — CeWL can't execute JS
  • Try fetching a static version or sitemap.xml
  • Check if site blocks scrapers (Cloudflare, etc.)
  • Reduce minimum word length: -m 3

"Connection refused / timeout"

  • Check target is reachable: curl -I https://example.com
  • Increase timeout
  • Use --no-verify-ssl if SSL issue

"403 Forbidden from Cloudflare"

  • Use custom User-Agent: -u "Mozilla/5.0 (X11; Linux)"
  • Try --random-user-agent
  • Add delay: --delay 3
  • Use proxy: --proxy_host

"Wordlist is too large"

  • Filter by length: -m 8
  • Filter by count: -c then sort by frequency
  • Reduce depth: -d 1

"PDFs not being parsed"

  • Install pdftotext: sudo apt install poppler-utils
  • Use --pdf flag
  • Check if PDFs are actually linked on site

"CeWL is very slow"

  • Reduce depth: -d 1
  • Remove --delay
  • Skip PDFs and metadata if not needed
  • Target smaller subset of site

"Memory error on large sites"

  • Limit depth: -d 1
  • Run against specific sections
  • Split site into subdomains
